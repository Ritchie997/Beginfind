# Agent context: индекс

Документы здесь дают короткий, предметный контекст для работы с кодом. Не
загружайте все страницы сразу: выберите область задачи, прочитайте её справку,
затем откройте названные исходники и проверьте текущее поведение.

## Маршрут по задаче

| Нужно понять или изменить | Сначала прочитайте |
| --- | --- |
| Где реализована функция | [`DOMAINS.md`](DOMAINS.md) |
| API, метод, маршрут или доступ | [`API_INDEX.md`](API_INDEX.md), затем соответствующий `src/routes/*.routes.js` |
| Хранение, формат данных, миграция, бэкап | [`DATA_AND_FLOWS.md`](DATA_AND_FLOWS.md) |
| Экран, браузерная логика или статические ресурсы | [`FRONTEND.md`](FRONTEND.md) |
| Порядок запуска, middleware, общая архитектура | [`../PROJECT_MAP.md`](../PROJECT_MAP.md) и `src/server.js` |

## Типовые цепочки

```text
Изменение UI       public/views + public/*.js → /api → route → service/store → data
Изменение API      API_INDEX → route → middleware/access → service/store → client callers
Изменение данных   DATA_AND_FLOWS → store/schema → migrations → backup/restore → callers
Изменение прав     auth/access service → каждый изменяющий и читающий route → UI states
```

Для любой цепочки проверьте реальные импорты, обработчики и ошибки. Таблицы
маршрутов и документация являются навигацией; источником истины остаётся код.

## Быстрый контекст

- Backend — CommonJS + Express, точка сборки приложения `src/server.js`.
- Frontend загружается напрямую из `public/`, отдельного сборщика и `npm test`
  нет.
- `src/routes/` принимает HTTP-запросы; `src/services/` содержит доменную
  логику и хранилища; `src/db/` открывает SQLite и выполняет миграции.
- Статьи хранятся как JSON-блоки в `content/`, карты/миры — JSON, большая часть
  прочего состояния — SQLite и файлы загрузок.
- Пользовательские данные не входят в Git. Миграции и восстановление бэкапов
  могут менять данные на диске.
- `public/spa-router.js`, `public/maps/map-editor.js`, `public/editor-manager.js`
  и несколько stores велики. Ищите конкретные символы/обработчики; не читайте
  крупный файл целиком без необходимости.

## Протокол изменения

1. Проверить текущие branch/worktree и не затрагивать чужие изменения.
2. Сформировать конкретную цепочку вызова по таблицам выше.
3. Изменить минимальный набор связанных слоёв; не доверять UI как проверке
   доступа.
4. Выбрать проверку, соответствующую изменённому поведению. Если автоматических
   тестов нет, явно сказать, что и как проверено.
5. Если документ устарел, обновить только соответствующий раздел/страницу.

Основной короткий контракт для агентов находится в корневом [`AGENTS.md`](../../AGENTS.md).
