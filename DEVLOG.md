# Devlog

Краткий обзор вех разработки, составленный по истории Git. Это не полный
перечень коммитов и не журнал изменений текущей ветки; одноимённые fix-коммиты
сгруппированы. История отражает сообщения и состояние репозитория, а не заменяет
просмотр diff.

## 2026-10-30 — перенос создания и управления франшизами из админ-панели на публичную основу AllTell

- Модульные карточки хабов, авторасширяемое описание и выравнивание действий в таблицах:
  - Карточки хабов на странице франшизы и в воркспейсе приведены к единому размеру без деформации сетки.
  - Реализован модульный оверлей описания хаба поверх карточки (position: absolute; inset: 0; backdrop-filter: blur) с плавным раскрытием/закрытием по кнопке «Читать описание» и внутренним скроллом.
  - В предпросмотре хабов карточки каталога добавлено модульное окно-поповер описания по клику на иконку информации.
  - Поле описания в форме создания и редактирования хаба переведено на полное вертикальное авторасширение блока без внутреннего слайдера/скроллбара (overflow: hidden, data-autogrow) и без мышиного ресайза в углу (resize: none). Лимит описания в API расширен до 5000 символов.
  - Исправлена работа кнопки «Показать хабы» в каталоге AllTell: устранено несоответствие типов ID (строка из dataset против числа в Set/Map), добавлен middleware optionalAuth для публичного просмотра списка хабов без обязательной авторизации.
  - Переработан визуал предпросмотра хабов в карточках каталога: хабы больше не слипаются, каждый оформлен отдельной карточкой-плиткой со своим аватаром/иконкой, названием и бейджем статуса; модульный оверлей описания аккуратно перекрывает контейнер предпросмотра без изменения размеров карточки франшизы.
  - Кнопки действий в таблицах участников, ролей и каналов приведены к единому стилю: контейнер .alltell-table-actions, колонка .alltell-table-action-col, white-space: nowrap, согласованные отступы и иконки.

- Аватарки франшиз и хабов, оптимизация интерфейса каталога:
  - Добавлена возможность загрузки и удаления аватарок для франшиз (в модальном окне создания и во вкладке «Настройки» воркспейса).
  - Добавлена возможность загрузки и удаления аватарок для игровых хабов (в форме создания и редактирования хаба).
  - Отображение аватарок в карточках каталога («Моё AllTell» и общий каталог), в шапке вселенной, в персональной ленте обновлений, а также в карточках хабов и бейджах постов.
  - Удалена избыточная кнопка «Создать франшизу» рядом с заголовком «Каталог франшиз» (основная кнопка уже размещена в описании hero-секции страницы).

- Создание и полный воркспейс управления франшизами перенесены из админ-панели на публичную страницу AllTell (/alltell):
  - По клику на кнопку «Создать франшизу» (в hero-секции, шапке каталога и баннере) открывается модальное окно создания франшизы на основном сайте:
    - Интерактивное превью аватара с живой генерацией цвета по алгоритму вселенной и инициалами по мере ввода названия.
    - Ввод названия франшизы и описания с валидацией и отправкой через POST /api/servers.
    - Создатель автоматически становится администратором франшизы, после чего происходит мягкий переход во вкладку управления созданной франшизой.
  - Каталог франшиз:
    - Добавлены селекторы расширенной фильтрации (по наличию/статусу игровых хабов) и сортировки (по дате, названию, количеству участников).
    - Сводные бейджи статистики по франшизам, хабам и участникам.
    - Индикатор роли создателя («Вы создатель») и кнопка быстрого удаления франшизы для её владельца с подтверждением.
    - Раскрывающийся аккордеон прямо в карточке каталога для быстрого предпросмотра хабов франшизы без перехода на отдельную страницу.
  - Раздел «Участники»:
    - Таблица участников франшизы со значками ролей, ID, именами и аватарами.
    - Модальное окно добавления участника с живым поиском по имени (GET /api/users/search) и резервным указанием ID.
    - Назначение ролей участникам и снятие роли по нажатию на крестик на чипе роли.
    - Исключение участников из сообщества.
  - Полнофункциональный воркспейс управления («Управление»):
    - Вкладка Обзор: сводные карточки метрик, инфоблок о системе ролей и быстрые кнопки перехода по разделам.
    - Вкладка Участники: администрирование участников франшизы.
    - Вкладка Роли: создание, редактирование и удаление ролей с настройкой уровня иерархии (0–99) и матрицы прав (чтение, отправка, каналы, роли, бан).
    - Вкладка Каналы: создание, редактирование и удаление текстовых и голосовых каналов вселенной.
    - Вкладка Хабы: создание ролевых хабов, редактирование названия и описания, переключение публичности, смена статуса сессии («Ведётся», «Приостановлено», «Завершено») и удаление хаба.
    - Вкладка Карты: просмотр интерактивных карт Leaflet, привязанных к миру, форма создания новой карты (POST /api/maps), быстрые ссылки на просмотрщик и редактор, блок календаря мира.
    - Вкладка Журнал действий: просмотр истории аудита событий франшизы с человекочитаемыми описаниями.
    - Вкладка Настройки: редактирование названия и описания франшизы, передача владения (для root) и «Опасная зона» с полным удалением франшизы.
  - Визуальный стиль адаптирован под кибер-космическую стилистику сайта: стеклянные поверхности с размытием фона, неоновые акценты, аккуратные формы и плавная анимация.

## 2026-10-29 — перенос редактора статей из админ-панели в публичную Antropedia

- Полнофункциональный редактор статей перенесён из админ-панели на публичную основу Antropedia по кнопке «Написать»:
  - Полное сохранение возможностей редактора: модульная система блоков (`EditorManager`), инлайн-форматирование текста (жирный, курсив, подчёркивание, зачёркивание, код, цветной маркер, скрытая фраза/спойлер), заголовки H1–H3, маркированные/нумерованные списки, чек-листы, цитаты, блоки кода, таблицы, горизонтальные разделители, wiki-ссылки (включая многослойные ссылки), изображения, работы из галереи, интерактивные карты Leaflet с метками, инфобоксы, плашки-примечания (callout), мульти-колонки, спойлер-секции, drag-and-drop блоков, разделение по Enter и буфер копирования/вставки блоков.
  - Вкладки режимов отображения: «Редактирование», «Просмотр» (живой рендеринг через `BlocksRenderer` в стиле Obsidian) и сплит-режим «Разделить» с одновременным редактированием и предпросмотром.
  - Полноценная система черновиков: локальное хранилище (`localStorage`), автосохранение раз в минуту с бейджем статуса, облачная синхронизация (`/api/drafts`, `/api/draft-folders`), модальное окно «Мои черновики» с деревом папок, хлебными крошками, поиском, созданием папок, выбором карточек и удалением.
  - Поддержка многослойности статей: переключение многослойного режима, список слоёв, добавление/дублирование слоёв, управление ролевым доступом к слоям (`system:*`, `server:*`) и чекбокс публичности слоя.
  - Выбор франшизы и хаба с автопостроением пути лора, загрузка и предпросмотр обложки (файл или URL), соавторство и публикация через API с перенаправлением на чтение опубликованной статьи.
  - Визуальный стиль полностью адаптирован под кибер-космический интерфейс AllTell: тёмный стеклянный фон с `backdrop-filter: blur`, неоновые акценты (`#818cf8`, `#5865f2`), плавные анимации переходов, аккуратные формы ввода, липкая шапка и стилизованное окно черновиков.
  - Кнопка «Написать» подключена в hero-секции, на тулбаре каталога и в нижнем баннере Antropedia, с поддержкой кнопки «Редактировать» прямо со страницы чтения статьи для её автора или администратора.

## 2026-10-25 — папки галереи

- В галерее появились личные папки и подпапки; карточки папок показывают только
  общее число изображений во всей вложенной структуре.
- Карточки папок получили коллаж-превью 4:3 из трёх изображений самой папки и
  её подпапок; название и количество изображений расположены под превью.
- В папке можно выбрать несколько файлов: каждый загружается отдельно как
  работа с названием из имени файла, последовательно добавляясь в папку.
- Перемещение работ и подпапок выполняется через выбор с меню назначения или
  перетаскиванием, как в управлении папками черновиков.
- Карточки папок встроены в masonry-ленту галереи между работами; работы,
  разложенные по папкам, не дублируются отдельными карточками в общей ленте.
  В сортировке по новизне папки расположены по времени создания среди работ;
  после создания пользователь сразу переходит в новую папку. Владелец может
  создать подпапку в основной галерее из меню конкретной папки, как в
  админ-панели.
  Публичная страница показывает все папки с автором набора и позволяет выйти
  из чужой папки. Работы внутри папок публичны независимо от ограничений по
  ролям; работы вне папок сохраняют прежние ограничения. Управлять папкой
  может только её владелец.
- В меню «⋯» на карточках доступны действия с работами и папками: изменение,
  перемещение, переименование и удаление.
- Свои работы можно перемещать между папками. Удаление папки удаляет всё её
  дерево подпапок и находящиеся в нём работы вместе с изображениями и
  социальными данными.
- Фильтр «Мои работы» в публичной галерее показывает только папки текущего
  пользователя, а не чужие папки из общей ленты.
- Публичная галерея показывает прогресс последовательной загрузки изображений
  в папку на кнопке загрузки, как и админ-панель.
- В папке каждая карточка открывает отдельную работу: лайки и комментарии
  сохраняются отдельно, а стрелки и свайп переключают работы с учётом
  пагинации. В папку можно переместить только работу с одним изображением;
  изменение и дозагрузка изображений для работы в папке заблокированы.

  выбранного хаба. Публикация в непубличный хаб для обычных пользователей
